# Task Time Tracker API

Backend REST-сервис для учёта рабочего времени сотрудников.

## Описание

Сервис позволяет:
- Создавать задачи с указанием названия, описания и статуса
- Фиксировать временные отрезки, затраченные сотрудниками на задачи
- Получать информацию о задачах и затраченном времени за период
- Валидировать входные данные и корректно обрабатывать ошибки


## Стек

Java 21, Spring Boot 3.2.5, MyBatis 3.0.3, Maven, PostgreSQL 15 (Docker), JUnit 5, Mockito, TestContainers, SpringDoc OpenAPI (Swagger UI), Bean Validation.

## Реализованные эндпоинты

### Tasks — Управление задачами

| Метод | Путь | Описание | Статусы |
|-------|------|----------|---------|
| `POST` | `/api/tasks` | Создать новую задачу | `201 Created` |
| `GET` | `/api/tasks/{id}` | Получить задачу по UUID | `200 OK` / `404 Not Found` |
| `PATCH` | `/api/tasks/{id}/status` | Изменить статус задачи | `200 OK` / `400 Bad Request` |

**Допустимые статусы задачи:** `NEW`, `IN_PROGRESS`, `DONE`

### Employees — Сотрудники

| Метод | Путь | Описание | Статусы |
|-------|------|----------|---------|
| `POST` | `/api/employees` | Создать сотрудника | `201 Created` |
| `GET` | `/api/employees/{id}` | Получить сотрудника по UUID | `200 OK` / `404 Not Found` |

### TimeRecords — Учёт времени

| Метод | Путь | Описание | Статусы |
|-------|------|----------|---------|
| `POST` | `/api/time-records` | Создать запись о затраченном времени | `201 Created` |
| `GET` | `/api/time-records` | Получить записи за период (фильтры: `employeeId`, `taskId`, `dateFrom`, `dateTo`) | `200 OK` |

## Сборка и запуск приложения

### 1. Запуск базы данных (PostgreSQL)

Для работы приложения требуется запущенный контейнер PostgreSQL.

В корне проекта находится файл `docker-compose.yml`. Запустите БД следующей командой:

```bash
docker compose up -d
```
**Конфигурация подключения по умолчанию:**

| Параметр | Значение |
|----------|----------|
| Хост | `localhost` |
| Порт | `5400` |
| Имя БД | `task_tracker` |
| Пользователь | `postgres` |
| Пароль | `admin` |

> **Примечание** Эти параметры уже настроены в `application.yml` и `docker-compose.yml`.

### 2. Запуск приложения

В корне проекта выполните:

```bash
# Очистка и сборка проекта
mvn clean package

# Запуск JAR-файла (требует предварительно запущенную БД)
java -jar target/Task-Time-Tracker-0.0.1-SNAPSHOT.jar
```
